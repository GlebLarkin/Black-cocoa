# Лабораторная работа № 13. Колебательная релаксация CO₂

Метод Кантровица, глава 13 лабника («Л.р. 16»). В [отчёте](main.pdf) обработаны измеренные перепады при 24 и 65 °C без поправки на аппаратные потери. Потери обсуждаются как возможный источник расхождения с моделью. Развёрнутые ответы на все 11 вопросов вынесены в [отдельный PDF](questions.pdf).

## Что осталось уточнить

- **Водяной манометр.** По воспоминанию участников, в протокол сразу записывали разность уровней. Значения использованы напрямую.
- **Время релаксации.** Около 16 мкс получено для одной точки при 24 °C. У остальных пяти отношение ΔS/ΔSₘₐₓ больше единицы, поэтому время по графику не определяется. Повторные замеры CO₂ и контрольные отсчёты на воздухе при тех же давлениях позволят оценить воспроизводимость и вклад установки.
- **Манометр ресивера.** Основной расчёт опирается на записанные 200 делений на 1,6 кгс/см². Проверка для 100 делений даёт времена для всех шести точек, но при 49 делениях давление выходит за рекомендованные 1,6 атм. Результаты обеих калибровок в `data/manometer_scale_check.csv`. Сверить шкалу прибора и единицы записи `p0_air = 1.1`.
- **Прогрев.** Для фактической оценки нужны расход или диаметр сопла, температуры газа до и после ресивера и смысл записи «V ≈ 300 мл». Цилиндр Ø35 мм × 60 см даёт около 577 мл. В отчёте рассчитана требуемая мощность для примеров скорости по тепловому балансу.

## Как пересобрать

Сырые записи в [data.txt](data.txt). Рабочие значения заданы в `SERIES` в [main.py](main.py). Скрипт использует основную ветвь [графика со стенда](data/photo_2026-11-18_03-14-11.jpg), выправляет перспективу по углам рамки и сохраняет точки в `data/stand_curve.csv`. Расчётные значения пишутся в `data/results.csv`. Пустые ячейки времени означают, что измерение лежит вне оцифрованной ветви. Справочные оценки получены по рис. 13.1 лабника.

Из этой папки:

```sh
python3 main.py
latexmk -pdf main.tex questions.tex
cp main.pdf ../pdf/Ларькин.pdf
```

Для скрипта нужны NumPy, Matplotlib и Pillow. При обновлении графиков оставляйте редкие экспериментальные точки маркерами.
